Prompt Engineering
========================================

Prompt Engineering is the process of writing effective instructions for LLMs.

Best Practices:
- Be specific
- Provide examples
- Define output format
- Use step-by-step instructions

Example:
"Summarize this article in 3 bullet points."

RAG (Retrieval-Augmented Generation)
========================================

RAG combines:
1. Document Loading
2. Text Splitting
3. Embeddings
4. Vector Storage
5. Retrieval
6. LLM Generation

Benefits:
- Uses your own documents
- Reduces hallucinations
- Produces more accurate answers

Applications:
- PDF Q&A
- Chat with Documents
- Knowledge Bases
- Customer Support Bots

Typical RAG Workflow
========================================

1. Load documents
2. Split text into chunks
3. Generate embeddings
4. Store vectors in Chroma/FAISS
5. Retrieve relevant chunks
6. Send context to LLM
7. Generate final answer
